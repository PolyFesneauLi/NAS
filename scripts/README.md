# NAS 部署脚本使用说明

## 脚本概览

本目录包含NAS系统的三个核心部署脚本，支持分布式存储部署。

## 脚本列表

### 1. `deploy.bat` - 部署配置脚本
- **功能**: 通过命令行交互方式配置所有参数
- **特点**: 支持自定义所有配置项，创建分布式存储环境
- **使用**: 首次部署或需要修改配置时使用

### 2. `start-nas.bat` - 启动脚本
- **功能**: 启动NAS服务器和客户端
- **特点**: 自动安装依赖、检查端口、启动服务
- **使用**: 配置完成后启动整个系统

### 3. `stop-nas.bat` - 停止脚本
- **功能**: 停止所有NAS相关服务
- **特点**: 精确停止指定端口的进程
- **使用**: 需要停止服务时使用

## 使用流程

### 首次部署

1. **配置系统**
   ```cmd
   cd scripts
   deploy.bat
   ```

2. **启动服务**
   ```cmd
   start-nas.bat
   ```

3. **停止服务** (需要时)
   ```cmd
   stop-nas.bat
   ```

## 配置参数说明

### 默认配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 服务器端口 | 5000 | 服务器监听的端口号 |
| 存储路径 | F:\Code\NAS_DEMO\NAS\storage\uploads | 文件存储的绝对路径 |
| 存储主机IP | 10.172.79.26 | 存储服务器的IP地址 |
| 存储主机名称 | storage-server | 存储服务器的主机名 |
| MongoDB URI | mongodb://localhost:27017/nas | MongoDB数据库连接字符串 |
| JWT密钥 | nas_secret_key | JWT认证密钥 |
| 最大文件大小 | 21474836480 | 单个文件最大大小(字节) |
| 默认存储配额 | 536870912000 | 用户默认存储配额(字节) |

### 分布式存储配置

系统支持分布式部署，当前主机作为存储服务器：

- **统一存储**: 所有文件存储在 `STORAGE_PATH` 指定的绝对路径
- **网络访问**: 其他客户端通过 `STORAGE_HOST_IP` 访问
- **主机标识**: 使用 `STORAGE_HOST_NAME` 标识存储服务器

## 故障排除

### 常见问题

1. **MongoDB连接失败**
   - 确保MongoDB服务已启动
   - 检查连接字符串是否正确

2. **存储路径权限错误**
   - 确保指定的存储路径存在
   - 检查路径的读写权限

3. **端口被占用**
   - 脚本会自动寻找可用端口
   - 检查是否有其他服务占用端口

4. **配置文件不存在**
   - 运行 `deploy.bat` 创建配置

### 测试命令

```cmd
# 测试MongoDB连接
node -e "require('mongoose').connect('mongodb://localhost:27017/nas').then(() => console.log('MongoDB连接成功')).catch(err => console.log('MongoDB连接失败:', err.message))"

# 测试端口
netstat -an | findstr :5000
```

## 网络配置

### 防火墙设置

确保以下端口开放：
- **5000**: 服务器API端口
- **27017**: MongoDB端口 (如果使用远程数据库)

### 网络访问

其他客户端可以通过以下方式访问：
```
http://10.172.79.26:5000/api/files/upload
http://10.172.79.26:5000/api/files/download/:id
http://10.172.79.26:5000/uploads/:filename
```

## 安全建议

1. **修改默认密钥**: 在生产环境中使用强JWT密钥
2. **配置防火墙**: 限制网络访问
3. **定期备份**: 备份重要数据和配置
4. **监控日志**: 定期检查服务器日志

## 扩展配置

### 多存储节点

如需配置多个存储节点：
1. 修改 `STORAGE_HOST_IP` 为负载均衡器IP
2. 配置多个存储路径
3. 实现文件分发逻辑

### 高可用配置

1. **数据库集群**: 配置MongoDB副本集
2. **存储冗余**: 配置RAID或分布式存储
3. **负载均衡**: 使用Nginx等反向代理
