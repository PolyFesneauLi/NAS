# NAS文件管理系统使用手册

## 系统要求

在运行本系统之前，请确保您的计算机已安装以下软件：

1. **Node.js** (版本 14.0.0 或更高)
   - 下载地址：https://nodejs.org
   - 安装后请确保在命令行中可以运行 `node -v` 命令

2. **MongoDB** (版本 4.0.0 或更高)
   - 下载地址：https://www.mongodb.com/try/download/community
   - 安装后请确保MongoDB服务已启动

## 快速开始

1. **首次运行**
   - 双击运行 `start.bat`
   - 脚本会自动检查环境、安装依赖并启动服务
   - 启动完成后会自动打开浏览器访问系统

2. **关闭系统**
   - 双击运行 `stop.bat`
   - 或直接关闭所有命令行窗口

## 功能说明

1. **用户管理**
   - 注册：首次使用需要注册账号
   - 登录：使用注册的账号密码登录
   - 注销：点击右上角的"注销"按钮

2. **文件操作**
   - 上传：点击"上传文件"按钮选择文件
   - 下载：点击文件列表中的"下载"按钮
   - 删除：点击文件列表中的"删除"按钮
   - 批量删除：选择多个文件后点击"批量删除"
   - 搜索：在搜索框输入文件名（支持中文）
   - 排序：可按文件名、大小、上传时间排序

3. **存储空间**
   - 系统会显示已用空间和总空间
   - 上传文件时会自动检查剩余空间

## 常见问题

1. **启动失败**
   - 检查 Node.js 是否正确安装
   - 检查 MongoDB 服务是否启动
   - 检查端口 3000 和 5000 是否被占用

2. **上传失败**
   - 检查文件大小是否超过限制
   - 检查存储空间是否足够
   - 检查网络连接是否正常

3. **中文文件名问题**
   - 系统完全支持中文文件名
   - 如遇到乱码，请确保系统使用 UTF-8 编码

## 目录结构

```
NAS/
├── start.bat          # 启动脚本
├── stop.bat           # 停止脚本
├── client/           # 前端代码
├── server/           # 后端代码
├── storage/          # 文件存储目录
└── README.md         # 使用手册
```

## 技术支持

如遇到问题，请检查：
1. MongoDB 服务是否正常运行
2. 端口 3000（前端）和 5000（后端）是否被占用
3. 网络连接是否正常
4. 系统日志是否有错误信息

## 注意事项

1. 请勿手动删除 storage 目录下的文件
2. 请定期备份重要文件
3. 建议定期清理不需要的文件
4. 如需修改配置，请编辑 .env 文件

## 安全建议

1. 请妥善保管账号密码
2. 定期更换密码
3. 不要将系统暴露在公网环境
4. 及时更新系统和依赖包
