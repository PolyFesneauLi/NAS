# NAS 网络存储系统用户使用手册

---

## 1. 项目背景与目的

### 1.1 项目背景

在当今数字化时代，文件管理和存储已成为企业和个人工作流程中不可或缺的一部分。传统的文件存储方式存在以下问题：

- **存储分散**: 文件分散在多个设备上，难以统一管理
- **访问不便**: 需要物理接触设备才能访问文件
- **协作困难**: 团队成员之间文件共享和协作效率低下
- **安全风险**: 本地存储容易因设备故障导致数据丢失
- **权限管理复杂**: 缺乏统一的权限控制机制

### 1.2 项目目的

NAS网络存储系统旨在解决上述问题，提供一个现代化的文件管理解决方案：

- **统一存储**: 提供集中化的文件存储服务，支持多用户访问
- **便捷访问**: 基于Web的界面，支持随时随地访问文件
- **高效协作**: 支持文件共享、标签管理和权限控制
- **安全保障**: 实现用户认证、权限管理和数据备份
- **智能管理**: 提供文件搜索、预览、分类等智能功能

## 2. 系统架构与组件

### 2.1 系统架构概述

NAS网络存储系统采用前后端分离的分布式架构，主要包含以下核心组件：

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│	 前端界面       │    │   后端服务       │    │   数据存储        │
│   (React.js)    │◄──►│   (Node.js)     │◄──►│   (MongoDB)     │
└─────────────────┘    └─────────────────┘    └─────────────────┘
         │                       │                       │
         │                       │                       │
         ▼                       ▼                       ▼
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   文件存储        │    │   缓存服务       │    │   负载均衡        │
│   (本地存储)      │    │   (Redis)       │    │   (Nginx)       │
└─────────────────┘    └─────────────────┘    └─────────────────┘
```

## 3. 安装与配置

### 3.1 系统要求

#### 3.1.1 硬件要求
- **处理器**: Intel Core i3 或 AMD 同等性能处理器
- **内存**: 最低 4GB RAM，推荐 8GB 或更高
- **存储空间**: 最低 10GB 可用空间，推荐 50GB 或更高
- **网络**: 支持局域网连接， 能ping通存储机的IP， 并能够有权限访问存储机的共享文件夹（如`10.172.79.26\storage\`）

#### 3.1.2 软件要求
- **操作系统**: Windows 10/11, macOS 10.14+, Linux (Ubuntu 18.04+)
- **Node.js**: 版本 16.0.0 或更高 (所有运行此系统的主机都要安装)
- **MongoDB**: 版本 4.4 或更高 (存储机)
- **浏览器**: Microsoft Edge (推荐), Chrome, Firefox

### 4.2 管理员操作

用户分为两种 ： 普通用户与管理员用户 ，管理员的特殊权限有

1. 用户权限管理
2. 文件上传与删除
3. 文件名修改与标签修改

#### 4.2.1 用户权限管理

##### 4.2.1.1 跳转到团队成员界面

##### 4.2.1.1 权限管理

###### 1) 同意/拒绝  新用户注册申请

对于新注册的用户，会发送申请给管理员  ，管理员可以同意或者拒绝这些注册请求



如果同意申请 ，用户状态会从待批准变成已加入，且是普通用户权限

【例： 同意申请后 testuser3 会变成和 testuser2一样的用户状态】

如果拒绝申请，该用户栏会从团队成员列表中消失

<img src="./assets/Admin_accept.png"  style="zoom:67%;" />

###### 2) 提升权限 / 删除权限

当用户状态是”已加入“时   我们可以提升用户权限或者删除用户

提升权限会将普通用户变为管理员

删除用户会将用户从文件列表中移除

【**注意：”admin“ 是顶层管理员 只有它不能被删除**】

<img src="./assets/Admin_revise.png"  style="zoom:67%;" />

#### 4.2.2 文件管理

##### 4.2.2.1 文件信息
